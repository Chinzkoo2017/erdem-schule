# Эрдэм сургууль — Онлайн анги

Нүүр хуудсыг (`index.html`) өөрчлөхгүй. Онлайн анги `/classroom/` дотор бие даан ажиллана.
Хуучин `classroom.html` нь `/classroom/` руу шилжүүлдэг.

## Зардал: €0 / сар
- **Hosting:** Cloudflare Pages (одоогийнх) — үнэгүй
- **Backend:** Supabase Free — 50 000 хэрэглэгч, 500 MB өгөгдөл, 1 GB файл
- Build алхам, npm, сервер шаардлагагүй. Цэвэр HTML/CSS/JS.

> Supabase free төсөл 7 хоног огт хэрэглэгдэхгүй бол түр зогсдог (dashboard-оос нэг товчоор сэргээнэ).
> Долоо хоног бүр хичээлтэй тул энэ асуудал бараг гарахгүй.

## Боломжууд
| Эрх | Юу хийх вэ |
|---|---|
| Сурагч | Шууд хичээлд орох, хичээл/видео, даалгавар илгээх (текст + зураг/аудио/PDF), 3 тоглоом (үгийн карт, кирилл үсэг, зураг таах), оноо, цуврал 🔥, шагнал |
| Эцэг эх | Хүүхэд бүрийн явц, долоо хоногийн идэвх, даалгаврын төлөв, багшийн сэтгэгдэл |
| Багш | Даалгавар шалгах (оноо + сэтгэгдэл), хичээл/даалгавар нэмэх, ангийн Zoom/Meet линк, сурагчдын явц |
| Админ | Дээрхээс гадна: хэрэглэгчдэд эрх/анги оноох, эцэг эхийг хүүхэдтэй холбох, анги нэмэх |

Монгол / Герман хэл солигдоно (нүүр хуудастай нэг тохиргоо).

## Демо
`config.js` хоосон байхад жишээ өгөгдөлтэй демо горимоор ажиллана.
Supabase тохируулсны дараа ч `/classroom/?demo` хаягаар демог үзэж болно.

## Supabase тохируулах (≈15 мин)
1. https://supabase.com → New project (Region: **Frankfurt — eu-central-1**, DSGVO).
2. **SQL Editor** → `supabase/schema.sql`-ийг бүтнээр нь хуулж **Run**.
3. **Authentication → URL Configuration**: Site URL = `https://erdem-schule.de/classroom/`
4. **Project Settings → API**: `Project URL` болон `anon public` түлхүүрийг `classroom/js/config.js`-д хуулна.
5. Сайт дээр өөрөө бүртгүүлээд, SQL Editor дээр өөрийгөө админ болгоно:
   ```sql
   update profiles set role = 'admin'
   where id = (select id from auth.users where email = 'TANY@EMAIL');
   ```
6. Админ цэс → **Ангиуд**: анги нэмж Zoom/Meet линк оруулна → **Хэрэглэгчид**: шинэ хүмүүст эрх оноож, эцэг эхийг хүүхэдтэй холбоно.

## Нууцлал (DSGVO)
- Бүх хүснэгт RLS-тэй: сурагч зөвхөн өөрийнхөө, эцэг эх зөвхөн өөрийн хүүхдийн өгөгдлийг харна.
- Хэрэглэгч өөрийн эрх/ангийг өөрчлөх боломжгүй (зөвхөн админ).
- Даалгаврын файл хаалттай bucket-д, 1 цагийн хугацаатай холбоосоор нээгдэнэ.
- `datenschutz.html`-д Supabase (Frankfurt)-ыг өгөгдөл боловсруулагчаар нэмэх шаардлагатай.

## Excel жагсаалт (хэрэглэгчдийг Excel-ээр удирдах)
Админ → **Excel жагсаалт** цэс. Excel бол эх сурвалж: файлаа оруулахад систем юу өөрчлөгдөхийг харуулж, нэг товчоор хэрэгжүүлнэ. Имэйл илгээгдэхгүй (үнэгүй багцын имэйл хязгаарт хамаарахгүй).

| Багана | Тайлбар |
|---|---|
| Овог нэр | |
| Имэйл / нэвтрэх нэр | Хүүхдэд имэйл хэрэггүй: `temuulen` гэж бичихэд хангалттай |
| Эрх | Админ · Багш · Сурагч · Эцэг эх |
| Анги | Байхгүй анги автоматаар үүснэ |
| Гэр бүл | Ижил кодтой эцэг эх ↔ хүүхэд автоматаар холбогдоно (жишээ нь `BAT`) |
| Нууц үг | Шинэ хэрэглэгчид. Хоосон бол автоматаар үүснэ (жишээ нь `Temee-4821`) |
| Шинэ нууц үг | Бөглөвөл одоогийн хэрэглэгчийн нууц үгийг солино |

Жагсаалтаас хасагдсан хүн устгагдахгүй, **идэвхгүй** болно (дахин нэмбэл сэргэнэ).

### Нэг удаагийн тохиргоо (≈5 мин, үнэгүй)
Хэрэглэгч үүсгэх нь нууц түлхүүр шаарддаг тул Supabase дээр жижиг функц ажиллана:
1. Supabase → **Edge Functions** → **Deploy a new function** → **Via Editor**
2. Нэр: `roster-sync`
3. `supabase/functions/roster-sync/index.ts` файлын агуулгыг бүтнээр нь хуулж буулгаад **Deploy**
4. Функцийн **Settings** (Details) → **Verify JWT** унтраах → Save. (Функц өөрөө админ мөн эсэхийг шалгана.)

`classroom/js/roster-core.js`-ийг өөрчилбөл `tools/build-edge.sh` ажиллуулж index.ts-ийг дахин үүсгэнэ.

## Гэр бүлийн даалгавар
Багш "Шинэ даалгавар" дээр **Эцэг эхтэй хамт хийх даалгавар**-ыг чагтлаад 10 бэлэн санаанаас сонгож болно.
Эцэг эх өөрийн самбар дээр **Хамт хийлээ** дарж баталгаажуулна (сэтгэгдэл бичиж болно). Хүүхэд +10 оноо авна. 3 гэр бүлийн даалгавар = "Гэр бүлийн баг" шагнал.

## Анхны нэвтрэлт ба баг
Excel-ээр үүсгэсэн эсвэл "Шинэ нууц үг" өгсөн хэрэглэгч анх нэвтрэхдээ нууц үгээ заавал сольж, сурагч бол эцэг эхтэйгээ хамт багийн нэр, тэмдгээ сонгоно ("Дараа" дарж алгасаж болно). Нэр дээрээ дарж (зүүн доод булан) хүссэн үедээ нууц үг, багаа сольж болно. Эцэг эх хүүхдийнхээ багийг өөрийн самбараас засна.

## Шинэчлэлтийн SQL
Өмнө суулгасан бол SQL Editor дээр дарааллаар нь нэг удаа ажиллуулна:
1. `supabase/migrations/002_roster_family.sql`
2. `supabase/migrations/004_team_image.sql` (003-ыг агуулсан: нууц үг солих, баг, багийн зураг)
3. `supabase/migrations/005_contact_reports.sql` (утас, холбоо барих имэйл, тайлангийн тохиргоо)
4. `supabase/migrations/007_learning_analytics.sql` (сурах явцын анализ)

`roster-sync` функцийг шинэчлэх: Edge Functions → roster-sync → **Code** → `index.ts`-ийн шинэ агуулгыг буулгаад **Deploy**.

## Имэйл тайлан (долоо хоног бүр, үнэгүй)
Ням гараг бүрийн орой эцэг эх бүрт хүүхдийн явцын тайлан очно. Илгээгч: Brevo (өдөрт 300 имэйл үнэгүй). Хуваарь: Supabase pg_cron.

1. **Brevo:** brevo.com дээр бүртгүүлэх → Senders, Domains → **Domains → Add a domain** → `erdem-schule.de` → гарч ирэх DNS бичлэгүүдийг (Brevo code TXT, 2 DKIM, DMARC) **IONOS → Domains & SSL → erdem-schule.de → DNS** хэсэгт нэмэх → Brevo дээр **Authenticate**.
2. Brevo → **SMTP & API → API Keys → Generate** → түлхүүрийг хуулах.
3. Supabase → Edge Functions → **Deploy a new function → Via Editor** → нэр `weekly-report` → `supabase/functions/weekly-report/index.ts`-ийг буулгах → Deploy → Settings → **Verify JWT** унтраах.
4. Supabase → Edge Functions → **Secrets**: `BREVO_API_KEY`, `SENDER_EMAIL` (жишээ нь `noreply@erdem-schule.de`), `REPLY_TO` (хариу очих имэйл), `CRON_SECRET` (урт санамсаргүй тэмдэгт мөр).
5. SQL Editor дээр `supabase/migrations/006_schedule_weekly_report.sql`-ийн `PASTE_CRON_SECRET`-ийг 4-р алхмын утгаар солиод ажиллуулах.
6. Админ → **Имэйл тайлан** → **Надад туршилтаар илгээх**.

## Сурах явцын анализ
Тоглоомын хариулт бүр (үг, үсэг, өгүүлбэр, нөхцөл) хадгалагдана. Нэг зүйлийг дараалан 3 удаа зөв хариулбал "цээжилсэн".
- **Багш → Анализ:** ангийн дундаж, сурагч бүрийн цээжилсэн үг/үсэг, зөв хариултын хувь, 7 хоногийн тоглолт, хугацаандаа илгээсэн даалгавар, ангийн хамгийн хэцүү үгс.
- **Эцэг эх:** хүүхэд бүрийн картанд "Сурах явц" хэсэг ба гэртээ давтах үгс.
- Сурагч энэ мэдээллийг харахгүй (RLS).
